# Aura Solutions Work System

This folder is ready to publish as a static website.

Files:
- index.html — Aura Solutions app
- manifest.webmanifest — installable web-app metadata
- service-worker.js — basic offline caching

For GitHub Pages, upload these files to the repository and publish the repository from its main branch/root.

## Archive

Earlier copies of the app are kept in `archive/old-builds/` for reference. The live app is `index.html`, `job.html` and `app.html` (opened at `/app`; the old long filename redirects there).
